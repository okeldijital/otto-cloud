# Otto 1.0.2

## Release workspace

- Reworked the release detail page around a clear ordered tracklist.
- Track rows can be expanded inline and edited without leaving the release.
- Added track tabs for details, artists & credits, publishing, and technical metadata.
- Publishing tabs surface work-level contributor shares, publishers, and PRO registrations.
- Persisted release track sequence using \`track_releases.position\`.
- Release attachments now expose their canonical attachment IDs so the release workspace can preview/download them inline.
- Existing release metadata, artwork, financial, media, contract, and artist-role capabilities remain available below the tracklist.

## 1.0.2 workspace polish

- Moved the track expand/collapse control beside the track number so it is visually distinct from reorder controls.
- Replaced JSON-only track credits editing with inline contributor, role, and split fields, including allocation totals.
- Removed the low-value technical track tab.
- Removed the duplicate release-level artist-role assignment card from Release resources; release artists remain managed in the primary Release artists card.
- Hardened release resource loading so an unavailable contracts list does not prevent documents, financials, media, or the rest of the release workspace from rendering.
- Raised the release artist search layer above the surrounding layout so result menus no longer distort or sit behind the frame.
