# Entitlement Promotion

Only **approved** or **active** Rights may promote candidates.

```
Right (approved|active) → PromotionManifest → EntitlementCandidate (pending)
  → Human review → RoyaltyEntitlement (approved)
```

Default allocation: percentage / fractional split from right parties (or owner / unassigned 100%).

Split validation requires total ≈ 100%.
