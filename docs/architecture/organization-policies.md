# Organization Policies

Stored on `iam_organizations.policies` JSON; defaults from platform config.

| Policy | Default |
|--------|---------|
| maxMembers | 500 |
| maxAdministrators | 50 |
| invitationTtlDays | from token policy (7) |
| requireMfa | false |
| allowedEmailDomains | [] (any) |
| locked | false |

Also: `mfaPolicy` column for MFA mode (A.4).
