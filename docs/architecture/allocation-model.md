# Allocation Model

| Type | Meaning |
|------|---------|
| percentage | Share of revenue |
| fixed | Fixed amount |
| priority | Ordered claims |
| residual | Remainder after others |
| pass_through | Pass-through |
| holdback / reserved | Held amounts |

Paired with **split types**: equal, fractional, weighted, priority, residual, nested.

Validation: fractional shares must total 100% (or 1.0 as fraction).
