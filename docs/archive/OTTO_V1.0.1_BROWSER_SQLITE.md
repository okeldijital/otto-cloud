# OTTO V1.0.1 — Archived Historical Material

**Status:** ARCHIVED — NOT PART OF OTTO CLOUD

This document preserves historical documentation from the original OTTO desktop/browser application for provenance only.

The archived V1 architecture used Browser + React/Vite + FastAPI + SQLite and included a desktop/macOS packaging workflow. That architecture is superseded by OTTO Cloud.
